# Operations Runbook

Healthy-path monitoring is deterministic and does not invoke an LLM. Inspect timer receipts, observer health, TaskAgent health endpoints and upload access independently.

When a check fails, preserve its normalized fingerprint and bounded evidence. The webhook-driven TaskAgent incident autopilot may reason over that evidence only after it has been provisioned, dry-run verified and activated.

Infrastructure changes require an approved issue, recoverable backup and explicit rollback command. Service restart is an action, not a diagnosis.
